# لوحة إدارة صالون الحلاقة — Node.js

تحتوي هذه الحزمة على **موقع لوحة الإدارة فقط** وخادم Node.js/Express وقاعدة البيانات وواجهات API التي يحتاجها تطبيق Flutter الأصلي. المساران `/` و`/admin` يفتحان لوحة الإدارة المحمية؛ لا تحتوي الحزمة على صفحات حجز للعملاء. مسارات `/api/mobile/*` واجهات خلفية للتطبيق وليست صفحات ويب.

## التشغيل

تحتاج Node.js 22 أو أحدث وpnpm 10. بعد إعداد MySQL ومتغيرات Manus OAuth على بيئتك، نفّذ `pnpm install` ثم `pnpm db:migrate` ثم `pnpm dev`. يعمل الموقع افتراضيًا على المنفذ 3000. قبل استقبال حجوزات فعلية، سجّل دخول المدير الأول في المعاينة الخاصة وعدّل الخدمات والأسعار ومواعيد العمل إلى قيم الصالون الحقيقية.

لا يتضمن الأرشيف مفاتيح أو أسرارًا. لا ترفع ملفات `.env` أو بيانات الاعتماد إلى مستودع GitHub عام.
